# Week 2 Complete: JavaScript Foundation & DOM 🧠

## Overview

This week transitioned our static UI into a dynamic, interactive application. We established the core syntax of JavaScript, learned how to make logical decisions, and built bridges between our logic and the HTML interface using the Document Object Model (DOM).

## Master Concept Checklist

### 1. Variables & Data

- **Keywords:** `let` (mutable) and `const` (immutable).
- **Data Types:** Handled Strings, Numbers, Booleans, and structured lists using Arrays (`[]`).

### 2. Logic & Control Flow

- **Conditionals:** Utilized `if`, `else if`, and `else` to route execution paths based on boolean evaluations.
- **Switch Statements:** Evaluated single expressions against multiple `case` clauses for cleaner multi-condition logic.
- **Loops:** Implemented `while` and `do-while` loops to execute code blocks repetitively, particularly for array traversal using index counters (`i`).

### 3. DOM Manipulation

- **Selection:** Targeted HTML elements using `getElementById` (single) and `querySelectorAll` (NodeList/multiple).
- **Modification:** Dynamically altered element content via `.textContent` and applied CSS rules via `.classList.add()` and `.style`.

### 4. Events

- **Interactivity:** Bound behavior to user actions using `.addEventListener()`.
- **Form Handling:** Intercepted submissions using the `submit` event and prevented default HTTP POST refreshes using `event.preventDefault()`.

### 5. Functions & Architecture

- **Syntax:** Mastered both Function Declarations (`function name() {}`) and Function Expressions (`const name = function() {}`).
- **Data Handling:** Passed external data into functions via Parameters/Arguments and retrieved processed data using `return` statements.

## Capstone Application

Engineered the "Top 5 Priority Board". This project acts as a culmination of Week 2, featuring real-time form validation, array-based state management, loop-driven DOM rendering, and a batch-update system that targets multiple DOM nodes simultaneously based on conditional array states.
