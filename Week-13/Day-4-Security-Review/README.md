# Day 4 – Application Security & OWASP Top 10

## Project: Application Security Review Dashboard

A professional security review checklist built using HTML, CSS and JavaScript.

The project helps review application security controls,
identify weaknesses and track security improvements.

---

## 1. Concepts Learned

### OWASP Top 10
A list of major web application security risks published by OWASP.

### Input Validation
Checking user-provided data before accepting or processing it.

### Zod
A JavaScript validation library used to validate incoming data
against predefined schemas.

### XSS (Cross-Site Scripting)
An attack in which malicious JavaScript is injected into a website.

### CSRF (Cross-Site Request Forgery)
An attack that tricks an authenticated user's browser into
sending unwanted requests.

### SQL Injection
An attack that inserts malicious SQL commands through application input.

### Rate Limiting
Restricting the number of requests allowed within a specific time.

### Brute-Force Protection
Protecting login systems against repeated password guessing attempts.

### CSP (Content Security Policy)
A security policy that controls which resources a browser can load.

### HSTS (HTTP Strict Transport Security)
A security header that tells browsers to communicate using HTTPS.

### Helmet
Express.js middleware that helps configure HTTP security headers.
